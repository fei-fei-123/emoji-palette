# Emoji Palette 特性

Windows 表情快速上屏工具:呼之即来、呼之即去、键盘流优先、中英拼音混搜、纯 Unicode 上屏。

## 面板

- 全局热键呼出(默认 `Alt+E`,可自定义),任何应用前台均可触发
- 面板在光标处弹出,屏幕边缘自动收拢;预创建常驻,呼出无冷启动延迟
- 关闭途径:`Esc` / 点击面板外 / 上屏完成,任一即时生效,无动画
- 再按一次热键 = 收起面板
- 深色 / 浅色主题
- 底部信息栏:当前项大图预览 + 中文名 + 英文名 + 码点 + 已配置别名

## 搜索

- 四路命中,任一方式都能找到同一个 emoji:
  - 中文:`屎` → 💩
  - 英文:`shit` / `poop` → 💩
  - 拼音全拼:`shi` / `bianbian` → 💩
  - 拼音缩写:`bb` → 💩
- 三级排序:匹配档位(精确 > 前缀 > 子串)> 本地使用频率 > 码点
- 频率学习:每次上屏自动计数,常用 emoji 越用越靠前
- 自定义别名:右键任意 emoji → 添加搜索别名(如 `翔` → 💩),保存即生效,搜索与文本扩展共用

## 数据

- Unicode 官方全量 emoji(3700+,跟随 emoji-test 最新版本)
- 8 大分类 + 常用栏(频率 Top + 固定常用条)
- 数据源:Unicode CLDR 中英注解 + emojilib 英文俚语补充 + pypinyin 拼音预计算
- 运行期零网络;按本机 Segoe UI Emoji 字形覆盖自动隐藏不支持的 emoji(防豆腐块)

## 键盘流

- 导航模式(默认焦点):`←→` 横移、`↑↓` 纵移、`+/−` 切分类、`Enter` 上屏
- 输入模式:打字自动进搜索框,`↑↓` 回面板导航
- 搜索模式下数字 `1-9` 直选前 9 项
- `Shift+Enter` 上屏后保持面板(连续上屏),选中项自动下移
- `Home/End/PgUp/PgDn` 支持

## 上屏

- 纯 Unicode 字符注入(Win32 `SendInput`),**不经过剪贴板**,不破坏已复制内容
- 终端、代码编辑器、浏览器地址栏、任何接受文本输入的窗口通用
- 注入失败时(如提权窗口)自动降级为复制到剪贴板 + 托盘气泡提示

## 文本扩展

- `::` 前缀触发(可自定义):任意输入框打 `::shit` + 空格 → 自动回删并上屏 💩
- 输入法形态候选条:跟随光标定位、绝不抢焦点、数字直选、`←→` 移动选择
- 空缓冲时候选条展示常用 emoji,不打字也能选
- IME 感知:中文输入法处于转写模式时自动让位,不干扰正常打字
- 进程黑名单:游戏、远程桌面等进程前台时完全旁路
- 触发词表 = 自定义别名 + 内置关键词(英文/拼音/缩写,可关闭内置)

## 设置与系统集成

- 系统托盘常驻:显示面板 / 暂停热键 / 暂停扩展 / 设置 / 开机自启 / 退出
- 设置窗:热键录制(强制要求修饰键,防止吞字)、扩展配置、别名表格管理、外观(主题/图标尺寸/面板宽度)、自启
- 开机自启写 HKCU Run 注册表,打包态与开发态均支持
- 单实例锁(命名互斥体)
- 键盘钩子看护:监听线程失活自动重挂并提示
- 退出时强制卸载全部钩子,任何情况下不卡键盘

## 技术特性

- Python 3.11+ / PySide6;运行期仅依赖 `PySide6` 与 `keyboard`
- Win32 交互全部 `ctypes` 直调,无 pywin32 依赖
- 键盘安全硬约束:钩子回调只做 O(1) 操作,异常路径一律放行
- 测试:89 项(状态机表驱动 / 搜索打分 / IME 门禁 / 面板按键 / 索引完整性)
